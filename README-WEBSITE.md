# Portfolio website

Upload `index.html`, `styles.css`, and `script.js` to the root of your existing `Cybersecurity-SOC-Portfolio` GitHub repository.

Before publishing, replace these placeholders inside `index.html`:
- `YOUR_GITHUB_URL`
- `YOUR_LINKEDIN_URL`
- `YOUR_EMAIL`
- `YOUR_CV_FILE.pdf`

Then enable GitHub Pages:
1. Repository Settings
2. Pages
3. Deploy from a branch
4. Select `main`
5. Select `/ (root)`
6. Save

Because this site is designed for the root of your existing portfolio repository, the Lab 01-13 project links use your current folder names directly.
